Политика обработки персональных данных

Настоящая политика определяет порядок обработки персональных данных пользователей сайта hr-di (далее — «Сайт»), принадлежащего Шуплецовой Диане (далее — «Оператор»).

1. Какие данные собираются

При заполнении формы на Сайте Оператор получает: имя, номер телефона, тип интересующей вакансии и комментарий, который пользователь указывает самостоятельно.

2. Цели обработки

  • Связь с пользователем по оставленной заявке;
  • Консультация по услугам внешнего HR-отдела и подбору персонала;
  • Уточнение деталей вакансии.

3. Передача данных третьим лицам

Данные из формы передаются Оператору через защищённый сервис-посредник (Telegram-бот) исключительно для оперативного получения заявки. Данные не передаются третьим лицам в маркетинговых или иных целях.

4. Срок хранения

Персональные данные хранятся не дольше, чем это необходимо для целей обработки заявки, либо до момента отзыва согласия пользователем.

5. Права пользователя

Пользователь вправе запросить удаление своих персональных данных, обратившись к Оператору по контактам, указанным на Сайте.

6. Согласие на обработку

Заполняя форму на Сайте, пользователь подтверждает своё согласие на обработку персональных данных в соответствии с настоящей политикой.
